# Calculator

## 概要
The Odin Projectの課題として制作した、ブラウザ上で使用できる計算機です。

## Live Demo
[デモ](https://yukimaru753.github.io/Calculator/)

## 使用技術
- HTML
- JavaScript

## 機能
- 四則演算
- 小数の計算
- バックスペース
- AC（All Clear）
- キーボード入力

## 学んだこと
- DOMイベントの処理
- 計算状態の管理
- キーボードイベントの扱い
- `find()`を使ったDOM要素の検索
- 既存のクリック処理をキーボード入力でも再利用する方法
